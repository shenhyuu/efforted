# 织痕 · 部署与运维

版本：v1.0 · 目标：单台 VSS/家用主机即可跑通全链路

---

## 1. 本地开发

当前可运行的开发命令：

```bash
# 后端
cd backend
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --port 8000

# 前端
cd frontend
pnpm install
pnpm dev
```

当前后端依赖由 `requirements.txt` 锁定，数据层使用标准库 `sqlite3`，启动时自动建表；前端开发服务器已配置 `/api` 代理。生产目录拆分和迁移工具待业务增长后再引入。

`.env`（后端）：

```
SECRET_KEY=<openssl rand -hex 32>
DB_PATH=./data/zhihen.db
SINGLE_USER_MODE=true
```

## 2. 生产部署（裸机 + Systemd + Nginx）

```bash
# 前端构建产物（当前包管理器为 pnpm）
pnpm build           # dist/ 交给 nginx 托管

# 后端
pip install -e .
alembic upgrade head
```

生产后端命令是 M0 完成后的目标配置；在 `pyproject.toml` 与 Alembic 配置落地前不可直接使用。

`backend.service`：

```ini
[Unit]
Description=ZhiHen API
After=network.target

[Service]
User=zhihen
WorkingDirectory=/opt/zhihen/backend
EnvironmentFile=/opt/zhihen/.env
ExecStart=/opt/zhihen/.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
Restart=always

[Install]
WantedBy=multi-user.target
```

Nginx（TLS via certbot；前端 history 路由回退）：

```nginx
server {
  listen 443 ssl http2;
  server_name zhihen.example.com;

  root /opt/zhihen/frontend/dist;
  index index.html;

  location /api/  { proxy_pass http://127.0.0.1:8000; }
  location /docs  { proxy_pass http://127.0.0.1:8000; }
  location /files/ { proxy_pass http://127.0.0.1:8000; }
  location /      { try_files $uri $uri/ /index.html; }
}
server { listen 80; return 301 https://$host$request_uri; }
```

要点：单 worker 足矣（SQLite 写锁 + 个人规模）；如需多 worker，须保证单写进程或接受 WAL 下的 busy 重试。

## 3. Docker Compose（可选）

```yaml
services:
  zhihen:
    build: .
    environment: [ SECRET_KEY=${SECRET_KEY} ]
    volumes:
      - ./data:/opt/zhihen/backend/data      # 数据库与导出文件唯一持久化点
    ports: [ "127.0.0.1:8000:8000" ]
    restart: always
```

## 4. 数据备份（产品承诺的一部分）

- 每日 03:00 cron：`sqlite3 data/zhihen.db "PRAGMA wal_checkpoint(TRUNCATE);"` 后复制为 `YYYYMMDD.db`（保留 30 份；可选 age 加密）。
- 用户端「导出」是产品功能（F7），备份是运维兜底——两者都不缺失。
- 恢复 = 停服 + 换回文件 + 启动（Alembic 检查 `user_version` 自动补迁移）。

## 5. 监控与日志

- 不引入第三方统计 SDK（隐私红线）；日志仅记录：请求方法/路径/状态码/耗时/错误码，**不记录请求体与任何用户内容**。
- 健康检查：`GET /api/v1/health`（检查 DB 连接）；uptime-monitor 打它即可。
- 备份任务成功与否写入本地 `backup.log`。

## 6. 安全清单

- [ ] TLS 强制，HTTP 301
- [ ] `zhihen.db` 权限 600，属主 zhihen
- [ ] SECRET_KEY 不入库不入日志
- [ ] JWT 过期 30 天，登出即前端清除
- [ ] 导出文件 48h 自动清理
- [ ] 通知文案无敏感词（privacy_mode）
- [ ] 危机求助资源入口在设置页固定可达
