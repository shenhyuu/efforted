# 织痕 · 产品需求文档（PRD）

版本：v1.0 · 状态：定稿（MVP 开发依据）· 读者：全体开发与设计

---

## 1. 产品概述

### 1.1 一句话定义

织痕是一款「自我见证」工具：用户以最低成本（≤1 次点击、0 次打字）记录「我今天在这里」，产品以只增不减的「织痕布」呈现这些痕迹，并在用户最黑暗的时刻，把「你曾经用力过」温柔地送回眼前。

### 1.2 核心价值主张

> **在织痕里，唯一需要被记录的，不是你做得多好，而是——你曾经在这里。**

- 驱动机制：自我确认 + 被见证（非损失厌恶、非完成欲）
- 失败的定义：**系统中不存在「失败」这一概念**
- 时间观：回溯（你曾做过什么），非前瞻（今天要做多少）
- 低能量适配：一等公民，低能量是**主场景**而非边缘场景

### 1.3 产品公理（不可违背，评审最高依据）

| # | 公理 | 工程落点 |
|---|---|---|
| A1 | 不强迫努力 | 无目标、无缺口提醒、无「还差 X」类文案与接口 |
| A2 | 不强迫坚持 | 数据库永不存储连续天数字段；无断签概念；余烬机制替代 streak |
| A3 | 黑暗时点亮曾经的努力 | 回顾类内容只被主动打开，绝不主动推送；核心动作是回溯 |

**每次功能评审必答**：「一个正在崩溃、连起床都困难的人打开这个界面，会更好一点还是更糟一点？」答案为「更糟」即否决。

### 1.4 目标平台

响应式 Web App：
- 桌面浏览器（Chrome/Edge/Firefox/Safari 最新两个大版本）
- 移动浏览器（iOS Safari 16+、Android Chrome 110+）
- 可安装为 PWA（首屏 < 200KB、离线缓存只读页面、Check-in 离线排队）

## 2. 用户与场景

### 2.1 用户画像矩阵

| 画像 | 他们眼中的有效努力 | 记录时最大心理障碍 | 最小阻力路径（产品承接） |
|---|---|---|---|
| A. 高压备考党 | 「状态很差但我还是来了」「今天我没放弃」——相对自身基线的偏移量 | 记录即审判；害怕承认在意 | 一键「我在」，默认折叠时长 |
| B. 产后/新手父母 | 「我活着，并且照顾了一个人」 | 无产出不配记录；单手操作；时间被打碎 | 事后单点补记；拇指区大按钮；零打字提交 |
| C. 慢性疲劳/抑郁康复期 | 「我今天起床了」——10% 电量下做成的事 | 自我监控滑向反刍；二重羞耻 | 零输入记录；能量三档可跳过；低能量模式 |
| D. 长周期成果延迟者（研究生/转型） | 探索、试错、排除一条错误路径 | 习得性无助；不敢开始 | 「走过的路」区记录负结果（计为资产） |
| E. ADHD/神经多样性 | 同备考党，更依赖即时确认 | 时间盲；启动困难 | 计时器不显示倒计时；痕迹只降温不归零 |

### 2.2 关键场景（验收用例）

- **S1 深夜崩溃**：躺在床上、屏幕最暗、手在抖 → 3 秒内、单手完成一次 Check-in。
- **S2 47 天后回归**：打开首页 → 只看到「你回来了。」+ 重启卡片（过去痕迹被温柔调出），无追问、无离开天数、无愧疚设计。
- **S3 中断**：计时中离开 → 「我先歇会儿」，时长累加不归零，生成断点卡片。
- **S4 低谷期打开**：开启低能量模式 → 界面只剩「我还在」按钮与一句陪伴文案，全部数字隐藏。
- **S5 产后碎片**：哄睡后单手补一句「趁他睡着改了简历」→ 一条完整记录，无需开始/结束。
- **S6 隐私焦虑**：通知栏不含敏感词；一键导出全部数据；一键彻底清空（灰烬模式）。

### 2.3 贯穿性洞察

所有画像的痛点同构：**害怕被自己的记录审判**。产品要解决的不是「如何更自律」，而是「如何让自我观察不再危险」。

## 3. 功能规格与优先级

排序原则：**情感安全性 > 记录阻力降低 > 回顾价值 > 功能丰富度**。

### 3.1 P0（MVP 必须有）

#### F1 碎片化 Check-in（「我在」）

- 首页常驻大按钮，一次点击完成一条记录：时间戳 + 用户当时的能量档（可选）+ 可选一句话（可空）。
- 无开始/结束概念 → 无失败概念。
- 提交后无任何评价性反馈，只看到新的痕迹线被织入布中。
- 按住 3 秒的「我还在」变体（低能量模式主按钮）。

**验收**：从锁屏到完成记录 ≤ 3 秒、≤ 1 次点击、0 必填打字。

#### F2 能量/情绪状态标记

- 三档：**低 / 中 / 够用**（不用「差/好」，不用五档——低能量时做不了精细判断）。
- **永远可跳过**，跳过不产生任何「未标记」的视觉缺口。
- 是织痕配色的数据源（不是统计页的素材）。
- MVP 不提供滑块（滑块也是决策负担）。

#### F3 回溯补录时间轴

- 补录 = 与即时记录**完全同等地位**的记录（同一张表，无「补录」标记暴露于 UI 审判性位置）。
- 极简版：日期可选「今天/昨天/更早的某天」，也可以直接跳过；跳过日期的记录统一显示为「过去」，不推断具体日期。时段（早上/下午/晚上/深夜）与一句话均可跳过。
- **不做精确到分钟的补录计时**（避免补录变成精算负担）。

#### F4 弹性计时器（无惩罚暂停，**次入口**）

- 首页不放正中，进入路径为「如果你想计个时」。
- 无倒计时显示（倒计时制造紧迫感）；以柔光呼吸动画代替数字跳动。
- 暂停按钮文案「我先歇一会儿」；中断后时长自动累加、**永不归零**；生成断点卡片（「你在这里停下了，那时你已经走了 23 分钟」）。
- 结束文案固定：「今天就到这里。」
- 页面关闭/断电/断网：计时状态持久化，回来后继续。

#### F5 织痕时间线（首页呈现层）

- 每条记录 = 一根线；颜色由能量档决定；按时间顺序编织成「布」。
- **只增不减**：无下跌、无缺口、无红色；密度疏 = 「布纹的呼吸」。
- 久别回归首屏：「你回来了。」+ 重启卡片（「你上一次离开时……你之前也离开过 37 天，后来你回来了。这是第 4 次。」重启次数是被温柔看见的事实，不是污点）。
- **余烬机制**：长期未更新只表现为「余温」，痕迹只降温、永不熄灭、永不删除。

#### F6 「留一盏灯」时间胶囊

- 用户在状态好时给未来的自己写一句话，设定「在你撑不住的时候打开」。
- **绝不主动推送**；入口固定为「当你觉得撑不住的时候，打开这里」。
- 打开时展示原话 + 当时的能量语境（「写下它的时候，你也很累，但你还是记下了它」——强调力所能及处的出现，避免高光反衬当下）。

#### F7 数据主权（底线功能）

- 一键导出：JSON（全量结构化数据）+ PNG（织痕长卷，仅图案无数据）。
- 一键彻底清空（需一次确认，进入 48 小时可撤销宽限期；到期后立即物理删除，确认文案不做挽留）。
- 灰烬模式：保留视觉图案、清空全部文字内容。

### 3.2 P1（核心闭环验证后）

| 功能 | 关键约束 |
|---|---|
| F8 低能量模式（Lite） | 手动开关（+ 可选的静默检测：连续多日无记录只做界面自动降级，**不发通知**）；只剩「我还在」按钮 |
| F9 生成式周报（质性） | 先做规则模板版，LLM 后置；**用户主动索取才生成**；只复述事实（「这周有 3 天的记录发生在早上」）；禁止人格化赞美与一切转折/评价词；提供「我不想被总结」永久选项 |
| F10 自定义努力单位 | 预设优先（读一页/一道题/一次出门/一次深呼吸），自定义藏二级入口；**永不参与统计比较、不设总量目标** |
| F11 语音速记 | 浏览器 Web Speech API，转文字入一句话字段 |
| F12 「回声」机制 | 长期未出现时**一条**回溯式存在确认（「你曾在这里用力过，我记得」）；非催促；推送默认关闭 |
| F13 本地优先/离线 | PWA Service Worker；离线 Check-in 排队同步 |

### 3.3 P2（后置且谨慎）

匿名共鸣社区（单向投递、无计数、无排序、无回复、无关注；含危机干预）、回顾型成就系统（仅自我对照、可全隐藏）、多端同步、分享导出织痕长卷、白噪音（不绑定时长、不统计、不计入痕迹）。

### 3.4 明确反对的功能（不商量，写入代码 lint 级约束）

| 功能 | 反对理由 |
|---|---|
| 连续打卡 streak | 损失厌恶工业化；中断=归零=重击；对能量波动人群结构性歧视。替代：累计「出现次数」与「重启次数」，永不归零 |
| 排行榜/好友可见 | 社会比较摧毁自我参照的胜任感 |
| 目标缺口提醒 | 外部控制型动机，破坏自主性 |
| 惩罚性视觉（枯树/红叉/失望表情） | 制造回避条件反射 |
| 「你已连续 N 天」类鼓励 | 「连续=好」本身就是评判 |
| 催促推送/红点/二次挽留 | 暗黑模式 |
| AI 陪伴对话 | 廉价共情比没有共情更伤人；替代专业求助风险 |

## 4. 交互与文案规范

### 4.1 禁用词表（前端文案 lint 检查项）

坚持、加油、别放弃、落后、效率、自律、达成率、突破、战胜自己、失败、还差、已断、连续 X 天、清零、目标、自律、欠、落后、努力不够。

### 4.2 禁用符号与视觉

感叹号、火焰、奖杯、向下箭头、红色警示色、绿色/红色二元判定色、进度条、折线图（任何会下跌的图表）。

### 4.3 语气规范

- **陈述句 + 具体事实 + 时间锚点**（「上周三的这个时候，你在读第 4 章」）。
- 不用祈使句，不做人格化赞美，不做因果归因。
- 空状态文案示例：「这里还很空，也很好。留白也是生命的一部分。」「今天想被记下点什么吗？哪怕只有一句话。」
- 退出不挽留、无二次确认弹窗。
- 「不记录，也是被允许的。」需在合适位置显式出现。

### 4.4 通知规则（MVP 可仅做站内）

默认全部关闭；开启后每条推送「看完关掉也不亏」，不带任何行动要求；允许静默周、允许永久沉默；通知文案不含敏感词（「抑郁」「情绪」等，防设备共用场景）。

### 4.5 低能量可用性底线（每个页面必须满足）

- 核心动作 ≤ 3 秒、≤ 1 次点击、0 必填打字。
- 每屏有「低能量逃生口」：一键可完成的记录入口。
- 所有可选字段跳过后界面不显示「未标记」。

## 5. 非功能需求

| 维度 | 要求 |
|---|---|
| 性能 | Check-in 接口 P95 < 150ms；首屏（移动网络）< 2s；离线可完成 Check-in |
| 隐私 | 单用户本地优先；数据不用于任何推荐/训练；导出与删除为一级功能；传输全程 TLS |
| 危机兜底 | 设置页固定位置「如果你需要真正的帮助」：心理援助热线（中国：全国24小时心理援助热线；北京 010-82951332 等）与求助指引；以陪伴卡片形态，不弹窗、不诊断、不替代专业帮助 |
| 可靠性 | 计时状态断电可恢复；数据库 WAL + 每日备份 |
| 可维护性 | 文案集中在语言包（便于禁用词 lint）；DB 无任何 streak 字段为结构性红线 |

## 6. 核心用户故事（开发拆条依据）

| ID | 用户故事 | 验收标准 |
|---|---|---|
| US-1 | 作为低谷期用户，我只想点一下证明我在 | 首页一次点击生成记录；无任何后续必填步骤 |
| US-2 | 作为低能量用户，我不想被询问状态 | 能量档可跳过；跳过后时间线不出现缺口标记 |
| US-3 | 作为被打断的计时者，我不怕暂停 | 暂停后累加；刷新/断电后计时状态恢复 |
| US-4 | 作为补记者，我事后补录与实时记录同权 | 补录记录在时间线中与实时记录视觉无差异标注 |
| US-5 | 作为回归者，我不被追问 | 首屏只有「你回来了」+ 重启卡片；无离开天数 |
| US-6 | 作为隐私敏感者，我能随时带走或销毁数据 | 导出 JSON/PNG；清空需确认一次且不被挽留 |
| US-7 | 作为撑不住的人，我能打开自己留的灯 | 留一盏灯只有主动打开入口；系统绝不推送它 |
| US-8 | 作为设备共用者，通知不暴露我 | 通知栏/标题不含敏感词 |

## 7. 替代性成功指标（不用 DAU/留存衡量）

- **低谷回访率**：连续 N 天未记录后再次打开的比例（真正证明产品有用的时刻）。
- **主观无压迫感**：单题问卷「刚才用的时候，你感觉被评判了吗？」。
- **「什么都没做」会话占比**：打开又关掉、无任何记录的会话——这个数字应被珍惜而非优化。

---

## 8. 风险与红线（摘要，详见产品分析）

1. 温柔变成新 KPI → 不评价用户如何使用产品；提供「什么都不做模式」。
2. 空洞夸赞 → 只复述事实，禁止人格评价。
3. 回顾辉煌变对比伤害 → 回顾必须携带当时能量语境；绝不主动推送。
4. 廉价共情 → 周报只描述不诊断不建议；句式黑名单自动化 lint。

> 这个 App 存在的意义，是让下一次迈步的代价小一点。
