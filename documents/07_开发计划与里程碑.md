# 织痕 · 开发计划与里程碑

版本：v1.0 · 假设：1 名全栈开发（学生课余时间）或 2 人小组；总周期约 6~7 周到 MVP 上线

---

## 0. 总原则

- **每个里程碑都可用、可打开、可记录**——不让任何阶段产出「跑不起来的半成品」。
- 每个里程碑结束跑一次**评审清单**（见 PRD §1.3）与 copy lint，不合格不进入下一阶段。

## 1. M0 · 骨架（0.5 周）

- [x] FastAPI + SQLite(WAL) 可运行骨架（v0.1 使用标准库 `sqlite3`，暂不引入 SQLAlchemy/Alembic）
- [x] Vue 3.5 / Vite 8 / TypeScript 6 / Pinia 4 / Router 5 骨架（保留原生 CSS，不额外引入 Tailwind）
- [x] 认证：单账户 setup/login/logout（数据库持久化的不透明会话令牌）
- [x] CI：后端 pytest、前端 vitest、Playwright、copy/schema lint
- 验收：登录后能看到空首页；OpenAPI `/docs` 可用。

## 2. M1 · 心跳：Check-in + 能量三档（1 周）

- [x] `POST /checkins`、`GET /records`、records 表
- [x] 首页 CheckinButton（单击即记录）、EnergyPicker（可跳过）
- [x] 移动端适配（拇指区大按钮）
- 验收：US-1/US-2 通过；从锁屏到记录完成 ≤3 秒 ≤1 点击。

## 3. M2 · 织痕布 + 补录（1.5 周）

- [x] `GET /weave` 聚合服务 + WeaveCanvas（只增不减、织入动画、最多 2000 根线）
- [x] `POST /records/backfill` + BackfillView（全部字段可跳过；日期缺省时统一归入「过去」）
- [x] 余烬温度计算与视觉透明度
- 验收：S2/S5 场景通过；Canvas 2000 线段 <8ms；补录记录与实时记录视觉无差异。

## 4. M3 · 弹性计时器（1 周）

- [x] timers/timer_segments 表 + API（start/pause/resume/close）
- [x] TimerView：柔光呼吸、无倒计时、断点卡片、隐藏数字模式
- [x] 断电恢复（GET 实时计算 + 前端镜像）
- 验收：S3 通过；刷新/关页面后计时状态恢复；无任何「失败/放弃」端点与文案。

## 5. M4 · 留一盏灯 + 回归（1 周）

- [x] lamps 表/API + LampView（写信/打开，无推送）
- [x] `GET /comeback` + ComebackCard（动态计算，无冗余统计字段）
- [x] 断点卡片联动计时历史
- 验收：US-5/US-7 通过；API 层不存在 lamp 推送端点。

## 6. M5 · 数据主权 + 低能量模式（1 周）

- [x] 导出 JSON/PNG（JSON 服务端生成；PNG 当前设备直接生成）
- [x] 一键清空（48h 宽限 + 撤销；后台任务到期物理删除）+ 灰烬模式
- [x] LiteLayout 低能量模式 + 设置页 + 求助资源固定入口
- 验收：US-6 通过；低能量模式全路由只剩「我还在」。

## 7. M6 · PWA 离线 + 上线（1 周）

- [x] Service Worker、离线 Check-in 队列（IndexedDB + batch 幂等）
- [x] 系统深色模式、reduced-motion、基础键盘与语义可访问性
- [x] Nginx + TLS 路径 + Systemd 服务与每日备份 timer 配置
- [ ] 在真实服务器完成 TLS、备份恢复演练与正式 a11y 审计
- 验收：S1 在飞行模式下可完成 Check-in；全链路 https。

## 8. 上线红线复查（Release Gate）

- [x] 数据库 schema 无 streak/目标/进度/排名字段（schema lint）
- [x] 全部产品代码文案通过禁用词 lint
- [x] 无任何「你今天还没记录」类提醒代码路径
- [x] 留一盏灯、周报类回顾无主动推送调用
- [x] 导出/清空/灰烬全流程可用
- [ ] 通知默认关闭且无敏感词
- [x] 危机求助入口固定可达

## 9. P1 待办（上线后，按验证顺序）

低能量模式自动降级（静默）→ 规则模板周报（用户主动索取）→ 自定义努力单位 → 语音速记 → 回声机制（一条、默认关）。

## 10. 测试策略摘要

| 层 | 内容 |
|---|---|
| 单元 | 余烬公式、计时累加计算、comeback 判定、补录字段校验 |
| 集成 | API 全端点（含幂等、宽限期撤销、灰烬清空断言） |
| 前端 | 离线队列、timer 恢复、EnergyPicker 可跳过 |
| E2E（Playwright） | S1~S6 六个关键场景逐条跑 |
| 文案 lint | CI 每次构建必跑 |

> 一个提醒给未来的自己：排期紧张时，**砍掉的应该是功能，不是克制**。任何「先临时加个提醒、回头再删」的想法，都会留在这块布上成为永远拆不掉的一根刺。
