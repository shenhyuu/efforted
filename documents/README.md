# 织痕（ZhiHen）· 开发文档总览

> **别的工具记录你完成了多少，我们只记得你曾经用力过。**

## 项目定位

织痕是一款「非残忍」的自我见证类 Web App。它不督促努力、不强迫坚持，只做三件事：**陪伴、倾听、记录**——在用户最看不见自己价值的时候，替他们看见。

- **形态**：响应式 Web App（电脑 / 手机浏览器均可访问）
- **后端**：Python FastAPI + SQLite3
- **前端**：Vue 3 (Composition API) + TypeScript + Vite
- **部署**：单机可部署（一台 VPS 或一台笔记本即可跑通全链路）

## 文档说明

详细的产品、架构、数据库、接口、设计、运维和里程碑文档作为本地工作资料维护，不纳入公开 Git 仓库。运行与验证方法见项目根目录 `README.md`，实现细节以代码、自动化测试和 OpenAPI `/docs` 为准。

## 三条产品公理（所有技术决策的上位法）

1. **不强迫努力** → 系统中不存在「缺口」「目标进度」「还差 X」。
2. **不强迫坚持** → 数据库**永不存储 `streak`（连续天数）字段**；中断无任何状态变化。
3. **在最黑暗时替人点亮「你曾经努力过」** → 产品的核心动作是**回溯**，不是前瞻；回顾类内容（留一盏灯、重启卡片）**只被主动打开，绝不主动推送**。

## MVP（P0）范围一句话

一键「我在」Check-in、能量三档标记（可跳过）、回溯补录、织痕时间线可视化、弹性计时器（无惩罚暂停，次入口）、「留一盏灯」时间胶囊、数据导出与一键清空。
