# 织痕 · 前端设计规范（Vue 3）

版本：v1.0 · 读者：前端与设计

---

## 1. 设计语言：织痕隐喻

产品的全部视觉系统围绕一个隐喻构建——**一块永远织不完的布**。

| 隐喻元素 | 承载含义 |
|---|---|
| 线（thread） | 一条记录 |
| 线的颜色 | 记录时的能量档（暖米/浅杏/柔金，**无红无绿判定色**） |
| 布的疏密 | 记录的密度——疏是「布纹的呼吸」，不是缺失 |
| 余温（ember） | 长期未记录只表现为透明度下降，最低 0.15，**永不熄灭** |
| 雾 | 低能量时期的视觉表达（云雾变厚，而非颜色变暗） |

**视觉上不存在的东西**（等价于代码里禁止出现）：进度条、折线图、倒计时数字、红色/警示色、绿色完成色、徽章角标、感叹号、火焰、奖杯、向下箭头、叉。

## 2. Design Tokens

```css
/* styles/tokens.css（当前使用原生 CSS；引入 Tailwind 4 后与 @theme 同步） */
--c-bg:        #faf6f0;   /* 米白纸感，深夜模式 #1c1a18 */
--c-thread-low:    #c8b9a6;  /* 能量低：暖米灰 */
--c-thread-mid:    #d9b98c;  /* 能量中：浅杏 */
--c-thread-enough: #e8c86a;  /* 能量够用：柔金 */
--c-fog:       #efe9e1;   /* 雾/留白 */
--c-ink:       #4a4238;   /* 文字，不用纯黑 */
--c-ink-soft:  #8a7f72;   /* 次级文字 */
--radius: 14px;           /* 大圆角、无锐利边角 */
--shadow: 0 2px 12px rgba(74,66,56,.08);  /* 极轻投影 */
--font: "Noto Serif SC", "Source Han Serif", system-ui;  /* 衬线优先：书信感 */
```

排版原则：**低密度、大留白、正文 ≥16px、行高 1.8**；移动端拇指区（屏幕下 1/3）放置核心操作。

## 3. 页面与路由

| 路由 | 页面 | 内容 |
|---|---|---|
| `/` | Home | 织痕布 + 「我在」大按钮 + （如触发）重启卡片 |
| `/timeline` | Timeline | 全部痕迹流（纸带式，非统计） |
| `/backfill` | Backfill | 补录（四步全部可跳过） |
| `/timer` | Timer | 弹性计时（次入口，柔光呼吸） |
| `/lamp` | Lamp | 留一盏灯（写/开） |
| `/settings` | Settings | 模式开关/导出/清空/求助资源入口 |

路由守卫：`settings.low_energy_mode=true` 时，所有路由降级渲染 LiteLayout（只有一个按钮）。

## 4. 核心组件规格

### 4.1 CheckinButton.vue

- 首页常驻，直径 ≥ 96px，位于拇指区。
- 单击 = 提交（0 必填）；提交成功 → 一根新线以动画织入布中（600ms ease）。
- 长按 3s = 「我还在」极简模式变体（进度以柔光呼吸表现，非进度条）。
- 提交后**无评价性 toast**，只有织入动画本身。
- 离线时走 IndexedDB 队列（useOfflineQueue），UI 反馈「先收下了，等有网再织进去」。

### 4.2 EnergyPicker.vue

- 三档：`低 / 中 / 够用`，大圆点三选一；显眼的「先不选」按钮。
- 跳过后任何页面不显示「未标记」。
- 不是滑块（滑块 = 决策负担）。

### 4.3 WeaveCanvas.vue（核心组件）

- Canvas 2D 自绘：横轴时间（默认 180 天，可捏合缩放），每天一根纵向线；线的颜色由能量档映射，当日多条记录时以细线并排（密度感）。
- 交互：点击某天的线 → 展开当天的记录卡（纸带）。
- **只增不减**：新记录织入动画；无任何减少动画；数据为空的天显示雾色，无标记。
- 渲染层不计算任何统计（总数等数字默认隐藏，`hide_all_numbers` 控制）。
- 性能：`requestAnimationFrame` 只在数据变化/交互时绘制；≤2000 线段单帧 <8ms。

### 4.4 ComebackCard.vue

- 触发条件（首屏判定 `GET /comeback`，is_comeback=true 时显示）。
- 标题：「你回来了。」——不追问、不显示离开天数的其他位置。
- 内容：上次离开的痕迹提示 + 重启次数陈述（「这是第 4 次」，中性温柔）。
- 两个**视觉权重完全相等**的按钮：「补记那段时间」「直接开始新的」。

### 4.5 BreakCard.vue（断点卡片）

- 计时暂停时出现：「你在这里停下了，那时你已经走了 23 分钟。」+「痕迹不会消失。」
- 「我歇会儿」「我回来了」两个按钮视觉权重相等。

### 4.6 LampView

- 入口文案：「当你觉得撑不住的时候，打开这里。」
- 列表 + 写信（textarea 无字数统计、无「写多点」提示）。
- 打开一盏灯时：显示原文 + 当时能量语境（「写下它的时候，你也记录了自己的电量。它一直在。」）。
- **无任何到期提醒、无红点、无角标。**

### 4.7 LiteLayout（低能量模式）

- 隐藏：织痕布统计视图、一切数字、历史入口、设置复杂项。
- 只剩：一句陪伴文案（「不需要做什么。只是在这里，也算数。」）+ 一个「我还在」长按按钮。
- 大字（≥20px）、高对比暖色。

## 5. 状态管理（Pinia）

| store | 职责 |
|---|---|
| auth | token 存储（localStorage）、静默 401 重登 |
| records | 记录流缓存、乐观插入、离线队列 |
| timer | 计时状态本地镜像（启动时 `GET /timers/{id}` 恢复）、秒级 tick 由本地驱动、暂停/恢复调 API |
| settings | 低能量模式等，驱动布局守卫 |

计时器注意：**界面不显示倒计时数字**；流逝以柔光呼吸动画表现；数字仅在用户点「看看走了多久」时短暂浮现（且为正计时）。

## 6. 文案治理（前端部分）

- 全部文案集中在 `copy/zh-CN.ts`，结构化 key。
- CI 脚本对 copy 文件运行禁用词 lint（与后端共用 `scripts/copy_lint.py`），命中即 fail。
- 通知标题（PWA push）遵守 `privacy_mode`：默认标题仅为「织痕」，内容不含「情绪/抑郁/能量」等词。

## 7. 可访问性与低能量底线

- 核心路径键盘可达（Enter = Check-in）；焦点样式柔和但可见。
- 深夜模式（跟随系统 + 手动）；最低亮度下对比度仍达标（WCAG AA，正文 4.5:1）。
- 减动效：`prefers-reduced-motion` 时关闭织入/呼吸动画。
- 每屏「低能量逃生口」：任意页面右上常驻最小化的 Checkin 圆点。

## 8. 构建与质量

- 当前使用 Vite 8 构建；M6 引入尚未安装的 PWA 插件（precache App Shell；`/`、`/lamp`、`/backfill` 可离线打开）。
- M0 引入尚未安装的 Vitest，单测覆盖 stores（离线队列幂等、timer 恢复计算）与 copy lint。
- E2E（Playwright，可选）：S1 深夜崩溃场景 3 秒完成 Check-in；S3 断电恢复。
